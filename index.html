📜 本專案如何透過 AGENTS.md 讓 AI 自動擴充新頁面？

本網站並非單次 Vibe Coding 產物，而是建立在 AGENTS.md（員工手冊）規範上的可擴充系統。當老闆（使用者）下達指令「幫我新增鮮血君王蒙格的攻略頁」時，AI Agent 會自動執行以下四步標準作業流程（SOP）：

STEP 01 // CONTENT FIRST

撰寫內容數據稿

先在 notes/<slug>.md 整理頭目 HP、韌性、異常閾值與家豪點評，確保事實與數據先行。

STEP 02 // SELF-CONTAINED PAGE

生成獨立戰術網頁

套用 AGENTS.md 規定的黑金色票與三大類別模版，生成 guides/<slug>/index.html 與互動工具。

STEP 03 // INDEX REGISTRATION

註冊首頁目錄卡片

在根目錄 index.html 自動插入新卡片並綁定 data-category 與搜尋關鍵字。

STEP 04 // STATE SYNC

同步更新白板紀錄

更新 NOTES.md 完成進度與 log.md 架構決策，讓下次開啟對話的 AI 瞬間無縫接手。
